# Python Mastery Path

Learn Python progressively through topics, modules,
mini projects, and real-world projects.

## Learning Path

### 1. Topic Exercises

Practice core Python concepts.

- Strings
- Lists
- Dictionaries
- Loops
- Functions

### 2. Module Exercises

Master the Python standard library.

- pathlib
- shutil
- json
- csv
- pickle

### 3. Mini Projects

Combine multiple modules to solve practical problems.

### 4. Real-World Projects

Build useful tools that could be used personally or professionally.
